# SellxBD (আগের নাম F-Shop) — মাল্টি-শপ SaaS

দোকানদাররা নিজে সাইনআপ করে কয়েক সেকেন্ডে নিজের অনলাইন দোকান খোলে: প্রতিটা পণ্যের ল্যান্ডিং পেজ, ক্যাশ অন ডেলিভারি, ফেক অর্ডার আটকানো, Facebook Pixel + Conversions API, স্টাফ লগইন, নিজের ডোমেইন। আপনি প্রতি কনফার্ম অর্ডারে আর মাসিক চার্জ নেন।

**প্রযুক্তি:** Hono (TypeScript) · Cloudflare Workers · প্রতিটা দোকানের জন্য আলাদা Durable Object (নিজস্ব SQLite ডাটাবেস) · D1 (মূল ডাটাবেস) · R2 (ছবি) · সাধারণ CSS + vanilla JS · Vitest

## ১. কাঠামো এক নজরে

```
ourdomain.com                → হোম পেজ (দাম), সাইনআপ
ourdomain.com/super          → আপনার সুপার অ্যাডমিন
দোকান.ourdomain.com          → দোকানের সাইট (ফ্রি subdomain)
dokan.com / www.dokan.com    → দোকানের সাইট (দোকানদারের নিজের ডোমেইন)
যেকোনো দোকানের /admin        → সেই দোকানের ড্যাশবোর্ড
```

- **প্রতিটা দোকানের নিজস্ব আলাদা ডাটাবেস।** পণ্য, অর্ডার, কাস্টমার, ব্ল্যাকলিস্ট, সেটিংস আর স্টাফ দোকানের নিজের ডাটাবেসে থাকে (Cloudflare Durable Object)। এক দোকান অন্য দোকানের তথ্য কখনো দেখতে পারে না
- **মূল ডাটাবেস (D1)** — শুধু দোকানের তালিকা, ডোমেইন, ব্যালেন্স, লেনদেন আর রিচার্জ। কাস্টমারের কোনো তথ্য এখানে থাকে না
- ফেক অর্ডারের নিয়ম আর ব্ল্যাকলিস্ট দোকানভিত্তিক: এক দোকানে ব্লক হওয়া নম্বর অন্য দোকানে ব্লক নয়

## ২. Codespaces-এ চালানো

1. GitHub-এ repo → সবুজ **Code** বাটন → **Codespaces** → **Create codespace on main**
2. ২-৩ মিনিটে নিজে থেকে হবে: `npm install`, `.dev.vars` তৈরি, মূল ডাটাবেস তৈরি, ডেমো দোকান, তারপর port 8000-এ সাইট চালু
3. **PORTS** ট্যাবে port 8000-এর 🌐 আইকনে ক্লিক করুন

**Codespaces-এ subdomain চলে না**, তাই টেস্ট মোডে (`.dev.vars`-এ `DEV_MODE=1`):

| কী দেখতে চান | ঠিকানার শেষে লিখুন |
|---|---|
| যেকোনো দোকান | `?shop=দোকানের-ঠিকানা` (যেমন `?shop=demoshop`) |
| প্ল্যাটফর্মে (হোম/সাইনআপ/সুপার অ্যাডমিন) ফেরা | `?shop=` |

**ডেমো দোকানের মালিক লগইন** (শুধু লোকাল): `demo@fshop.test` / `demo12345`

**সুপার অ্যাডমিন বানানো:**

```bash
npm run super:create -- আপনার@ইমেইল.com
```

পাসওয়ার্ড দুবার চাইবে (কমপক্ষে ১০ অক্ষর)। তারপর প্ল্যাটফর্মে `/super`-এ লগইন করুন।

> **সাইট বন্ধ হলে:** `npm run dev`
> **নতুন কোড আনার পর:** `git pull && npm install && npm run db:migrate`
> **সব মুছে নতুন করে শুরু:** `npm run db:reset`

## ৩. পুরো প্রক্রিয়া হাতে পরীক্ষা

1. **সাইনআপ:** প্ল্যাটফর্মের হোম → "দোকান খুলুন" → ফর্ম পূরণ → সরাসরি নতুন দোকানের ড্যাশবোর্ড
2. **দোকান সাজানো:** সেটিংস (নাম, নম্বর, লোগো, রং, ডেলিভারি চার্জ) → ক্যাটাগরি → পণ্য
3. **অর্ডার:** দোকানের সাইটে একটা পণ্যে অর্ডার দিন → অ্যাডমিনে "কনফার্ম" করুন
4. **বিলিং:** অ্যাডমিন → বিলিং → রিচার্জের অনুরোধ পাঠান → সুপার অ্যাডমিন → রিচার্জ → অনুমোদন
5. **স্টাফ:** অ্যাডমিন → স্টাফ → একজন "অর্ডার স্টাফ" যোগ করুন → তার ইমেইলে লগইন করে দেখুন শুধু অর্ডার দেখা যায়
6. **সুপার অ্যাডমিন → সেটিংস:** আপনার আসল bKash/Nagad/সাপোর্ট নম্বর বসান, দরকার হলে দাম বদলান

## ৫. Cloudflare-এ লাইভ করা

> ✅ **এখন লাইভ:** https://sellxbd.com — Cloudflare **ফ্রি প্ল্যানে** চলছে (খরচ ৳০, শুধু ডোমেইনের দাম)।
> `main`-এ push করলেই টেস্ট চলে, সব পাস হলে নিজে থেকে লাইভ আপডেট হয়।

### যা সেটআপ করা আছে
- **ডোমেইন:** `sellxbd.com` Cloudflare-এ Active। DNS-এ `sellxbd.com` আর `*.sellxbd.com` (AAAA `100::`, proxied) — ডিপ্লয়ের সময় `scripts/ensure-dns.mjs` না থাকলে নিজে বানায়
- **মূল ডাটাবেস (D1):** `f-shop-platform` — id `wrangler.jsonc`-এ। টেবিল ডিপ্লয়ের সময় নিজে তৈরি/আপডেট হয়
- **ছবি:** R2 লাগে না — প্রতিটা দোকানের নিজের ডাটাবেসে থাকে (১MB-এর টুকরোয়), Cloudflare edge cache থেকে পরিবেশন হয়
- **পাসওয়ার্ড হ্যাশ:** PBKDF2 ২০,০০০ বার — ফ্রি প্ল্যানের ১০ms CPU সীমার মধ্যে (লগইনে ভুল চেষ্টার সীমাও আছে)
- **GitHub secret দুটো (আলাদা টোকেন):**
  - `CLOUDFLARE_API_TOKEN` — টোকেন "SellxBD deploy (GitHub)"; শুধু ডিপ্লয়ের job-এ থাকে, Worker-এ কখনো যায় না
  - `CF_WORKER_TOKEN` — টোকেন "SellxBD worker (domains)"; ডিপ্লয়ের সময় Worker-এর `CF_API_TOKEN` secret হিসেবে বসে (শুধু দোকানদারের ডোমেইনের কাজ — নিচে ৬ নম্বর)। এই secret না থাকলে Worker-এর আগের secret বদলায় না

### ফ্রি প্ল্যানের সীমা (বড় হলে Workers Paid $৫/মাস নেবেন)
- দিনে ১,০০,০০০ রিকোয়েস্ট (ছবি edge cache থেকে গেলে গোনা হয় না)
- একবারে বাল্ক কুরিয়ারে সর্বোচ্চ ২০টা অর্ডার
- Durable Objects (দোকানের ডাটাবেস) মোট ৫GB

Paid প্ল্যান নিলে কোড বদলাতে হবে না।

### টোকেন নষ্ট/ফাঁস হলে
Cloudflare → My Profile → API Tokens → যেটা ফাঁস হয়েছে ("SellxBD deploy (GitHub)" বা "SellxBD worker (domains)") → **Roll** → নতুন টোকেন কপি করে GitHub → Settings → Secrets and variables → Actions → মিলিয়ে `CLOUDFLARE_API_TOKEN` বা `CF_WORKER_TOKEN` → ✏️ → **Secret** ঘরে পেস্ট (নামের ঘরে নয়!) → Actions থেকে **Run workflow**।

**নিরাপত্তার নিয়ম (workflow):** টেস্টের job-এ কোনো টোকেন নেই; `npm ci --ignore-scripts`; actions commit SHA দিয়ে আটকানো; দুটো টোকেন কখনো একই হবে না (একই দিলে ডিপ্লয় থেমে যায়)। কোডে `guardZone` — Worker কখনো `sellxbd.com`-এর নিজের zone মুছতে বা তার DNS/Worker domain বদলাতে পারে না।

> **লাইভে টেস্ট মোড বন্ধ থাকে।** লাইভে `?shop=` কাজ করে না, শুধু আসল ডোমেইন/subdomain দিয়ে দোকান খোলে।

### সুপার অ্যাডমিন
লগইন: https://sellxbd.com/super — তারপর **সেটিংস**-এ bKash/Nagad/সাপোর্ট নম্বর বসান।
পাসওয়ার্ড বদলাতে বা নতুন সুপার অ্যাডমিন: Codespace-এ `CLOUDFLARE_API_TOKEN=টোকেন npm run super:create -- ইমেইল --remote`

## ৬. দোকানদারের নিজের ডোমেইন চালু করা

এর জন্য Worker-এর একটা আলাদা টোকেন লাগে, যেটা দিয়ে সিস্টেম দোকানদারের ডোমেইন আপনার Cloudflare অ্যাকাউন্টে যোগ করে। **এটা deploy টোকেন নয়** — এতে D1, R2, Workers ডিপ্লয়ের অনুমতি থাকবে না।

1. **API Tokens** → **Create Token** → **Create Custom Token** → নাম "SellxBD worker (domains)"। অনুমতি (এর বেশি নয়):
   - `Account` · `Workers Scripts` · `Edit`
   - `Zone` · `Zone` · `Edit`
   - `Zone` · `DNS` · `Edit`
   - `Zone` · `Workers Routes` · `Edit`
   - Account Resources: আপনার অ্যাকাউন্ট · Zone Resources: **All zones from an account** → আপনার অ্যাকাউন্ট
2. GitHub → Settings → Secrets and variables → Actions → **New repository secret** → নাম `CF_WORKER_TOKEN`, মান এই টোকেন → Actions থেকে **Run workflow** (ডিপ্লয় নিজেই Worker-এ বসাবে)

**দোকানদার যা করবে:** অ্যাডমিন → ডোমেইন → `dokan.com` লিখে যোগ করবে → দুটো নেমসার্ভার পাবে → নিজের ডোমেইন কোম্পানির প্যানেলে বসাবে → "এখনই যাচাই করুন" (অথবা সিস্টেম প্রতি ৩০ মিনিটে নিজে যাচাই করে)। নেমসার্ভার বসলে `dokan.com` আর `www.dokan.com`-এ দোকান https সহ চালু হয়।

**ইমেইল ইত্যাদি:** ডোমেইন যোগ করলে সিস্টেম আগের DNS রেকর্ড খুঁজে আনে। দোকানদার **DNS রেকর্ড** পেজে "সব গ্রহণ করুন" চাপলে ইমেইল (MX), TXT ইত্যাদি চালু থাকে। নতুন রেকর্ডও সেখানে যোগ করা যায়।

> নতুন Cloudflare অ্যাকাউন্টে একসাথে অনেক ডোমেইন যোগ করতে গেলে Cloudflare সাময়িক সীমা দিতে পারে। আপনার মূল ডোমেইন আগে Active থাকলে এই সমস্যা সাধারণত হয় না।

## ৭. Facebook Test Events দিয়ে ট্র্যাকিং যাচাই

প্রতিটা দোকানের Pixel আলাদা — দোকানদার নিজের **সেটিংস**-এ বসায়।

1. Events Manager → Pixel → **Pixel ID** কপি → **Settings** → Conversions API → **Generate access token**
2. দোকানের অ্যাডমিন → সেটিংস: Pixel ID, CAPI Access Token, Graph API ভার্সন (`v26.0`), আর **Test events** ট্যাবের Test Event Code
3. Test events ট্যাব খোলা রেখে দোকানের সাইটে:

| কী করবেন | ইভেন্ট |
|---|---|
| যেকোনো পেজ | PageView |
| ল্যান্ডিং পেজ | ViewContent |
| "কার্টে যোগ" | AddToCart |
| ল্যান্ডিং ফর্মে ক্লিক / চেকআউট পেজ | InitiateCheckout |
| অর্ডার দেওয়া | Lead |
| অ্যাডমিনে **কনফার্ম** | Purchase (শুধু Server) |

প্রতিটায় Browser আর Server দুটো আসবে, "Deduplicated" লেখা থাকবে। **টেস্ট শেষে Test Event Code ফাঁকা করে সেভ করুন।**

|---|---|
| ফ্রি ট্রায়াল | ১৪ দিন অথবা ৫০টা কনফার্ম অর্ডার, যেটা আগে শেষ হয়। কোনো চার্জ নেই |
| ট্রায়াল শেষে | দোকান "চালু" হয়, প্রথম মাসের চার্জ কাটে |
| প্রতি অর্ডার | ৳২, শুধু **কনফার্ম** অর্ডারে, একই অর্ডারে একবারই (ফেক/বাতিলে নয়) |
| মাসিক | ৳৯৯ + প্রতিজন স্টাফ ৳৯৯। নতুন স্টাফ যোগ করলে চলতি মাসের ৳৯৯ সাথে সাথে কাটে (ট্রায়ালে নয়) |
| রিচার্জ | দোকানদার bKash/Nagad-এ পাঠিয়ে Transaction ID দেয় → আপনি সুপার অ্যাডমিন → রিচার্জে মিলিয়ে অনুমোদন দেন |
| ব্যালেন্স মাইনাস | ড্যাশবোর্ডে সতর্কবার্তা; ৩ দিন পর দোকানে নতুন অর্ডার বন্ধ (কাস্টমার ফোন নম্বর দেখে), অ্যাডমিন চালু থাকে; রিচার্জ হলে সাথে সাথে চালু |

সিস্টেম প্রতিদিন বাংলাদেশ সময় সকাল ৬:১৭-তে মাসিক চার্জ আর ট্রায়াল শেষ হওয়া দোকান দেখে। সুপার অ্যাডমিন থেকে দোকান স্থগিত/বন্ধ, ট্রায়াল বাড়ানো আর ব্যালেন্স সমন্বয় (বোনাস/কাটা) করা যায়।

## ৯. ফেক অর্ডারের নিয়ম

সব নিয়ম সার্ভারে চেক হয় আর দোকানভিত্তিক:

1. ফোন নম্বর শুধু `01[3-9]XXXXXXXX`; `+880`, বাংলা অঙ্ক, স্পেস সব `01...` হয়ে সেভ
2. কার্টে প্রতি পণ্য একটাই, সার্ভারও ডুপ্লিকেট বাদ দেয়
3. একই নম্বর **বা** ডিভাইসের "নতুন" অর্ডার থাকলে নতুন অর্ডার নয়; কনফার্মের পর আবার দেওয়া যায়
4. ফেক বা বাতিল করলে নম্বর আর ডিভাইস স্থায়ী ব্লক (ব্ল্যাকলিস্ট থেকে আনব্লক করা যায়)
5. ডিভাইস আইডি কুকি + localStorage-এ, একটা মুছলে অন্যটা থেকে ফেরত
6. একসাথে কয়েকবার সাবমিটে lock, আর প্রতি IP মিনিটে ৫টা অর্ডারের সীমা (বাংলাদেশে অনেকে একই মোবাইল IP শেয়ার করেন — সমস্যা হলে `src/shop/lib/order-guard.ts`-এ `ORDER_RATE_LIMIT` বাড়ান)

## ১০. দোকানের ফিচার

| ফিচার | কোথায় | কে পারে |
|---|---|---|
| **থিম** — ক্লাসিক, মিনিমাল, বোল্ড; লোগো আর দুটো রং | অ্যাডমিন → সেটিংস | মালিক |
| **ল্যান্ডিং পেজ বিল্ডার** — সেকশন যোগ/সাজানো/লুকানো (হিরো, সুবিধা, ছবি, ভিডিও, রিভিউ, প্রশ্নোত্তর, কাউন্টডাউন, অর্ডার ফর্ম…); প্রিভিউ | পণ্য → "ল্যান্ডিং পেজ" | মালিক, ম্যানেজার |
| **ভ্যারিয়েন্ট** — সাইজ/রং ইত্যাদি, প্রতিটার আলাদা দাম ও স্টক; কাস্টমার একটা বেছে অর্ডার করেন | পণ্য → এডিট → অপশন | মালিক, ম্যানেজার |
| **কুপন** — টাকা/শতাংশ/ফ্রি ডেলিভারি, সর্বনিম্ন অর্ডার, মেয়াদ, মোট ব্যবহার সীমা, এক নম্বরে একবার | অ্যাডমিন → কুপন | মালিক, ম্যানেজার |
| **রিপোর্ট** — আজ/৭/৩০ দিন/মাস: অর্ডার, কনফার্ম রেট, বিক্রি, ফেক/বাতিল, সেরা পণ্য, চার্ট | অ্যাডমিন → রিপোর্ট | মালিক, ম্যানেজার |
| **কুরিয়ার** — Steadfast, Pathao, RedX | অ্যাডমিন → কুরিয়ার (সেটিংস), অর্ডার পেজ (পাঠানো) | সেটিংস মালিক; পাঠানো সব স্টাফ |
| **SMS** — নিজের গেটওয়ে দিয়ে কনফার্ম/শিপডে SMS | অ্যাডমিন → SMS | মালিক |

### কুরিয়ার

1. **অ্যাডমিন → কুরিয়ার**-এ নিজের মার্চেন্ট অ্যাকাউন্টের API তথ্য দিন:
   - Steadfast: Api Key + Secret Key
   - Pathao: Client ID, Client Secret, মার্চেন্ট লগইন ইমেইল ও পাসওয়ার্ড, Store ID (টোকেন নিজে নেয় আর সেভ রাখে)
   - RedX: API Access Token (+ ঐচ্ছিক পিকআপ স্টোর আইডি)
   - Pathao/RedX-এ "টেস্ট (sandbox) মোড" টিক দিয়ে আগে পরীক্ষা করা যায়।
2. অর্ডার **কনফার্ম** করুন → অর্ডার পেজে "কুরিয়ার" বক্স → কুরিয়ার, ক্যাশ কালেকশন, ওজন বাছুন। Pathao-তে শহর/জোন/এলাকা (না বাছলে Pathao ঠিকানা দেখে বোঝে), RedX-এ এলাকা বাছতেই হবে।
3. বুক হলে ট্র্যাকিং নম্বর সেভ হয়, অর্ডার নিজে **শিপড** হয়। "স্ট্যাটাস আপডেট" বাটনে কুরিয়ারের সর্বশেষ অবস্থা।
4. **একসাথে অনেক:** অর্ডার → কনফার্ম ট্যাবে টিক দিয়ে Steadfast বা Pathao-তে (একবারে সর্বোচ্চ ৫০টা)।
5. একই অর্ডার দুবার বুক হয় না; কুরিয়ার ভুল ফেরত দিলে অর্ডার কনফার্মই থাকে আর কারণ দেখায়।

### SMS

1. **অ্যাডমিন → SMS** → "SMS চালু" টিক → গেটওয়ে বাছুন:
   - **BulkSMSBD** বা **SMS.net.bd**: API Key (আর Sender ID) দিন
   - **অন্য গেটওয়ে**: API URL দিন, নম্বরের জায়গায় `{number}` (8801... আকারে) আর মেসেজের জায়গায় `{message}`। দরকার হলে POST আর বডি (JSON হলে `{` দিয়ে শুরু)। "সফল হলে রেসপন্সে যে লেখা থাকে" দিলে সেটা না মিললে ব্যর্থ ধরা হয়।
2. টেমপ্লেট বদলান — `{নাম}` `{অর্ডার}` `{টাকা}` `{দোকান}` `{কুরিয়ার}` `{ট্র্যাকিং}` বসানো যায়।
3. সেভ করে "টেস্ট SMS" দিয়ে নিজের নম্বরে পরীক্ষা করুন।
4. কনফার্মে আর শিপডে (কুরিয়ারে পাঠালেও) একবারই SMS যায়। লগে সব দেখা যায়, ব্যর্থ হলে "আবার পাঠান"।

> কুরিয়ার আর SMS-এর টেস্টগুলো নকল সার্ভার দিয়ে চালানো — লাইভ করার আগে আসল অ্যাকাউন্ট দিয়ে একবার পরীক্ষা করুন।

## ১০.১ সাপোর্ট সিস্টেম (টিকেট + লাইভ চ্যাট)

দোকানদার ↔ SellxBD টিম। ডাটা থাকে প্ল্যাটফর্ম D1-এ (`support_tickets`, `support_messages`, `canned_replies`), রিয়েল-টাইম চলে একটা Durable Object (`SupportHub`, WebSocket Hibernation — কেউ কথা না বললে ঘুমায়, খরচ প্রায় শূন্য)।

- **দোকানদার** (`/admin/support`): সব অ্যাডমিন পেজের কোণে 💬 চ্যাট বাটন; টিকেট (ধরন, গুরুত্ব, বিস্তারিত, স্ক্রিনশট); উত্তর এলে মেনুতে ব্যাজ, টোস্ট আর শব্দ; সমাধানের পরে ⭐ রেটিং।
- **টিম** (`/super/support`, রোল: মালিক/অ্যাডমিন/সাপোর্ট): ইনবক্স (চলমান/আমার/অ্যাসাইন হয়নি/দোকানের অপেক্ষায়/সমাধান), মেট্রিক্স (গড় প্রথম উত্তর, CSAT), দোকানের তথ্য আর 🔑 এক ক্লিকে দোকানের প্যানেলে প্রবেশ, 🔒 ভিতরের নোট, ⚡ তৈরি উত্তর, দায়িত্ব/গুরুত্ব/অবস্থা।
- **অনলাইন/অফলাইন**: টিমের কারও সুপার অ্যাডমিন পেজ খোলা থাকলে "অনলাইন"। অফলাইন বা অফিস সময়ের বাইরে (এখন ২৪ ঘণ্টা খোলা — সেটিংস থেকে বদলানো যায়) মেসেজ এলে অটো-উত্তর যায়, কথোপকথন টিকেট হিসেবে থাকে।
- **Telegram (ঐচ্ছিক, এখন বন্ধ)**: `/super/support/settings`-এ বট টোকেন আর chat id দিলে নতুন টিকেট/চ্যাট (আর টিম অফলাইনে থাকলে নতুন মেসেজ) Telegram-এ আসে।
- WebSocket না চললে পেজ নিজে পোলিং করে (১০–৩০ সেকেন্ড)।
