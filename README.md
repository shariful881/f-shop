# F-Shop

ল্যান্ডিং-পেজভিত্তিক ই-কমার্স সাইট: প্রতিটা পণ্যের আলাদা ল্যান্ডিং পেজ, কার্ট, ক্যাশ অন ডেলিভারি, ফেক অর্ডার আটকানোর নিয়ম, আর Facebook Pixel + Conversions API।

**প্রযুক্তি:** Hono (TypeScript) · Cloudflare Workers · D1 ডাটাবেস (SQLite) · R2 (ছবি) · সাধারণ CSS + vanilla JS · Vitest

## ১. Codespaces-এ চালানো

1. GitHub-এ repo খুলুন → সবুজ **Code** বাটন → **Codespaces** ট্যাব → **Create codespace on main**
2. ২-৩ মিনিট অপেক্ষা করুন। নিচের কাজগুলো নিজে থেকেই হবে:
   - `npm install` (প্যাকেজ ইনস্টল)
   - `npm run db:migrate` (ডাটাবেসের টেবিল বানানো)
   - `npm run db:seed` (২টা ক্যাটাগরি আর ৩টা নমুনা পণ্য)
   - port 8000 পাবলিক করা আর সাইট চালু করা (`npm run dev`)
3. ডানদিকে বা নিচে **PORTS** ট্যাবে port 8000-এর পাশের 🌐 আইকনে ক্লিক করলে সাইট নতুন ট্যাবে খুলবে
4. সব ঠিক আছে কি না দেখতে ঠিকানার শেষে `/health` লিখুন → `{"ok":true,"products":3}` দেখাবে

> **সাইট বন্ধ হয়ে গেলে** টার্মিনালে লিখুন: `npm run dev`
> **নতুন কোড আনতে:** `git pull` তারপর `npm install && npm run db:migrate`
> **ডাটাবেস একদম নতুন করে শুরু করতে:** `npm run db:reset` (সব অর্ডার মুছে যাবে)

লোকাল ডাটাবেস থাকে `.wrangler/` ফোল্ডারে (একটা SQLite ফাইল)। এটা GitHub-এ যায় না।

## ২. অ্যাডমিন বানানো ও ব্যবহার

টার্মিনালে:

```bash
npm run admin:create -- আপনার@ইমেইল.com
```

পাসওয়ার্ড দুবার চাইবে (টাইপ করলে `*` দেখাবে, কমপক্ষে ৮ অক্ষর)। একই ইমেইলে আবার চালালে পাসওয়ার্ড বদলে যায়।

তারপর সাইটের ঠিকানার শেষে **`/admin`** দিয়ে লগইন করুন।

**প্রথমে যা করবেন:**
1. **সেটিংস** → সাইটের নাম, যোগাযোগ নম্বর, ঢাকার ভিতরে/বাইরের ডেলিভারি চার্জ
2. **ক্যাটাগরি** → নিজের ক্যাটাগরি বানান, ক্রম ঠিক করুন (ছোট সংখ্যা হোম পেজে আগে দেখাবে)
3. **পণ্য** → নমুনা পণ্যগুলো বন্ধ করে নিজের পণ্য যোগ করুন (ছবি JPG/PNG/WebP, ৩ MB পর্যন্ত)

পণ্যের ল্যান্ডিং পেজের লিংক হবে: `https://আপনার-সাইট/p/slug` — এই লিংকটাই Facebook অ্যাডে দেবেন।

**অর্ডারের স্ট্যাটাস:**

| এখন | যেখানে বদলানো যায় |
|---|---|
| নতুন | কনফার্ম, বাতিল, ফেক |
| কনফার্ম | শিপড, বাতিল |
| শিপড | বাতিল |
| বাতিল / ফেক | আর বদলানো যায় না |

- **কনফার্ম** চাপলে Facebook-এ Purchase যায় (শুধু সার্ভার থেকে, একবারই)
- **বাতিল** বা **ফেক** চাপলে ওই অর্ডারের নম্বর আর ডিভাইস দুটোই স্থায়ীভাবে ব্লক হয়। ভুলে ব্লক হলে **ব্ল্যাকলিস্ট** পেজ থেকে আনব্লক করুন

## ৪. Facebook Test Events দিয়ে ট্র্যাকিং যাচাই

### ক. Pixel ID আর Access Token নেওয়া
1. [Facebook Events Manager](https://business.facebook.com/events_manager2) → আপনার Pixel (Dataset) বাছুন
2. **Pixel ID** কপি করুন (সংখ্যা)
3. **Settings** ট্যাব → **Conversions API** অংশে **Generate access token** → টোকেন কপি করুন

### খ. সাইটে বসানো
অ্যাডমিন → **সেটিংস** → Facebook অংশে:
- **Pixel ID** আর **CAPI Access Token** বসান
- **Graph API ভার্সন**: `v26.0` (Facebook নতুন ভার্সন দিলে এখানে বদলাবেন)
- Events Manager → **Test events** ট্যাব থেকে **Test Event Code** (যেমন `TEST12345`) কপি করে বসান

### গ. যাচাই
1. Events Manager → **Test events** ট্যাব খোলা রাখুন
2. আরেকটা ট্যাবে আপনার সাইট খুলুন, তারপর:

| কী করবেন | কোন ইভেন্ট আসবে |
|---|---|
| যেকোনো পেজ খুলুন | PageView |
| ল্যান্ডিং পেজ খুলুন | ViewContent |
| "কার্টে যোগ" চাপুন | AddToCart |
| ল্যান্ডিং ফর্মে ক্লিক করুন, বা চেকআউট পেজ খুলুন | InitiateCheckout |
| অর্ডার দিন | Lead |
| অ্যাডমিনে অর্ডার **কনফার্ম** করুন | Purchase (শুধু Server) |

3. প্রতিটা ইভেন্টের পাশে **Browser** আর **Server** দুটো আসবে, আর "Deduplicated" লেখা থাকবে (একই event_id, তাই Facebook একবারই গোনে)। Purchase শুধু **Server** থেকে আসবে
4. Purchase না গেলে অর্ডারের পেজে "Purchase যায়নি" আর Facebook-এর উত্তর দেখাবে, সাথে **Purchase আবার পাঠান** বাটন

> **টেস্ট শেষে Test Event Code অবশ্যই ফাঁকা করে সেভ করুন।** নাহলে আসল ইভেন্টগুলো শুধু টেস্টে যাবে, অ্যাডে কাজে লাগবে না।

**জেনে রাখুন:**
- Codespaces-এর লিংকে Pixel কাজ করে, তবে আসল ডোমেইনে লাইভ করার পরেই চূড়ান্ত যাচাই করুন
- Purchase-এ যায়: অর্ডারের সময় সেভ করা fbp, fbc, IP, ব্রাউজার, ডিভাইস আইডি (hash), ফোন নম্বর (8801XXXXXXXXX → SHA-256), মোট টাকা (BDT), পণ্যের আইডি, অর্ডার নম্বর
- event_id: `purchase_FS-100001` ধরনের, তাই একই অর্ডারের Purchase দুবার গোনা হয় না

## ৫. Cloudflare-এ লাইভ করা

একবার সেটআপ করলে এরপর থেকে GitHub-এর `main`-এ push করলেই সাইট নিজে আপডেট হবে।

### ধাপ ১: Cloudflare অ্যাকাউন্ট
[dash.cloudflare.com](https://dash.cloudflare.com) এ ফ্রি অ্যাকাউন্ট খুলুন।

### ধাপ ২: ডাটাবেস (D1) বানানো
1. বাম মেনু → **Storage & Databases** → **D1 SQL Database** → **Create**
2. নাম দিন: `f-shop-db` → **Create**
3. তৈরি হলে **Database ID** কপি করুন (লম্বা আইডি, যেমন `a1b2c3d4-...`)
4. GitHub-এ repo → `wrangler.jsonc` ফাইল → ✏️ এডিট → `"database_id": "00000000-0000-0000-0000-000000000000"` এর জায়গায় আপনার আইডি বসান → **Commit changes**

### ধাপ ৩: ছবির জায়গা (R2) বানানো
1. বাম মেনু → **R2 Object Storage** → **Create bucket**
2. নাম দিন: `f-shop-images` → **Create**

> প্রথমবার R2 চালু করার সময় Cloudflare একটা পেমেন্ট মেথড (কার্ড) চাইতে পারে। এটা যাচাইয়ের জন্য। ফ্রি সীমার মধ্যে (১০ GB পর্যন্ত ছবি) টাকা কাটে না।

### ধাপ ৪: API Token বানানো
1. ডান উপরে প্রোফাইল → **My Profile** → **API Tokens** → **Create Token**
2. **Edit Cloudflare Workers** টেমপ্লেটের পাশে **Use template**
3. **Permissions**-এ **+ Add more** → `Account` · `D1` · `Edit` যোগ করুন
4. **Account Resources** → আপনার অ্যাকাউন্ট, **Zone Resources** → All zones
5. **Continue to summary** → **Create Token** → টোকেন কপি করুন (একবারই দেখাবে)
6. **Account ID**: Cloudflare ড্যাশবোর্ডের হোম পেজে আপনার অ্যাকাউন্টের নামের পাশে, বা Workers পেজের ডানদিকে পাবেন

### ধাপ ৫: GitHub-এ secret বসানো
repo → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:
- `CLOUDFLARE_API_TOKEN` = ধাপ ৪-এর টোকেন
- `CLOUDFLARE_ACCOUNT_ID` = আপনার Account ID

### ধাপ ৬: লাইভ করা
repo → **Actions** ট্যাব → **Test & Deploy** → **Run workflow** (অথবা যেকোনো কিছু push করুন)।

২-৩ মিনিটে টেস্ট চলবে, লাইভ ডাটাবেসে টেবিল তৈরি হবে, আর সাইট লাইভ হবে। ঠিকানা হবে: `https://f-shop.<আপনার-নাম>.workers.dev` (Cloudflare → Workers & Pages → f-shop-এ দেখাবে)।

### ধাপ ৭: লাইভ সাইটে অ্যাডমিন বানানো
Codespace-এর টার্মিনালে:

```bash
export CLOUDFLARE_API_TOKEN=আপনার_টোকেন
export CLOUDFLARE_ACCOUNT_ID=আপনার_account_id
npm run admin:create -- আপনার@ইমেইল.com --remote
```

> লাইভ ডাটাবেসে নমুনা পণ্য থাকবে না। অ্যাডমিন থেকে নিজের ক্যাটাগরি আর পণ্য যোগ করুন, আর সেটিংস আবার বসান (লোকাল আর লাইভ ডাটাবেস আলাদা)।

## ৭. ফেক অর্ডারের নিয়ম কীভাবে কাজ করে

সব নিয়ম সার্ভারে চেক হয়, ব্রাউজারের JS বন্ধ করেও এড়ানো যায় না।

1. **ফোন নম্বর:** শুধু `01[3-9]XXXXXXXX`। `+880`, `880`, স্পেস, ড্যাশ, বাংলা অঙ্ক সব `01...` বানিয়ে সেভ হয়, তাই একই নম্বর ভিন্নভাবে লিখে নিয়ম এড়ানো যায় না
2. **কার্টে প্রতি পণ্য ১টা:** কোয়ান্টিটি নেই। আবার যোগ করলে "আগেই কার্টে আছে"। সার্ভারও ডুপ্লিকেট বাদ দেয়
3. **পেন্ডিং অর্ডার:** একই নম্বর **বা** একই ডিভাইসের কোনো অর্ডার "নতুন" থাকলে নতুন অর্ডার নেয় না। কনফার্ম করলে আবার দেওয়া যায়
4. **স্থায়ী ব্লক:** বাতিল বা ফেক করলে নম্বর আর ডিভাইস ব্ল্যাকলিস্টে যায়
5. **ডিভাইস চেনা:** প্রথম ভিজিটে একটা আইডি `did` কুকি আর ব্রাউজারের localStorage দুই জায়গায় রাখা হয়। একটা মুছলে অন্যটা থেকে ফিরে আসে। অর্ডারে IP আর ব্রাউজারের তথ্যও সেভ হয়
6. **একসাথে কয়েকবার সাবমিট:** একই নম্বর/ডিভাইসে lock থাকে, তাই একটাই অর্ডার হয়। আর একই IP থেকে মিনিটে ৫ বারের বেশি অর্ডার সাবমিট করা যায় না

> **Rate limit নিয়ে:** বাংলাদেশে অনেক মোবাইল ব্যবহারকারী একই IP শেয়ার করেন। অ্যাড চলার সময় আসল কাস্টমার "অনেকবার চেষ্টা করা হয়েছে" দেখলে `src/lib/order-guard.ts`-এ `ORDER_RATE_LIMIT`-এর `max` বাড়িয়ে দিন।

## ৮. দরকারি কমান্ড

| কমান্ড | কাজ |
|---|---|
| `npm run dev` | সাইট চালু (port 8000) |
| `npm test` | সব টেস্ট |
| `npm run db:migrate` | লোকাল ডাটাবেসে নতুন টেবিল/পরিবর্তন |
| `npm run db:seed` | নমুনা ক্যাটাগরি ও পণ্য |
| `npm run db:reset` | লোকাল ডাটাবেস মুছে নতুন করে শুরু |
| `npm run admin:create -- email` | অ্যাডমিন বানানো (লোকাল) |
| `npm run admin:create -- email --remote` | অ্যাডমিন বানানো (লাইভ) |
| `npm run deploy` | হাতে লাইভ করা (টোকেন লাগবে) |

## ৯. ফোল্ডার কাঠামো

```
.devcontainer/        Codespaces সেটআপ
.github/workflows/    টেস্ট + অটো ডিপ্লয়
migrations/           ডাটাবেসের টেবিল (SQL)
scripts/              DemoSeeder, admin:create
public/               CSS, JS, ছবি (সরাসরি পরিবেশন হয়)
src/
  index.tsx           অ্যাপের শুরু, middleware
  middleware/         ডিভাইস আইডি, Facebook কুকি, অ্যাডমিন লগইন, CSRF
  lib/                ফোন, কার্ট, অর্ডার, ফেক অর্ডারের নিয়ম, স্ট্যাটাস, CAPI
  routes/             দোকানের পেজ (shop) আর অ্যাডমিন (admin)
  views/              HTML টেমপ্লেট (JSX)
test/                 সব টেস্ট
wrangler.jsonc        Cloudflare কনফিগ (D1, R2)
```

**সুরক্ষা:** `.env`, `.dev.vars`, `node_modules/`, `.wrangler/` (লোকাল ডাটাবেস), `*.sqlite`, `public/uploads/*` কখনো GitHub-এ যায় না (`.gitignore`)। Facebook টোকেন শুধু ডাটাবেসে থাকে, কোডে নয়।
